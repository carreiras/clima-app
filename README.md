# Clima App

App didático de previsão do tempo em Kotlin + Jetpack Compose, consumindo a
API pública [Open-Meteo](https://open-meteo.com/en/docs). Construído aula a
aula, cada uma com seu próprio guia detalhado.

## Stack

Kotlin, Jetpack Compose + Material3, Hilt, Retrofit + Gson, Room, Navigation
Compose, Coroutines/Flow, WorkManager.
